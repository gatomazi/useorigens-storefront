# Ordem editorial oficial da home `/sul`

Atualização da hierarquia da home.

A ordem anterior deve ser substituída por esta:

```text
Hero
↓
Sua cidade, de 8 jeitos
↓
Da Nossa Terra
↓
Escolha seu estado
↓
Redesenhos / Releituras
↓
Feito Para Você
↓
O número de cada região
↓
Fala daqui
↓
Campanha editorial
↓
Footer
```

Essa passa a ser a ordem desejada para a V2 do `/sul`.

Não reorganizar novamente sem revisão.

---

# 1. Hero

Função:

```text
entrada
+
busca
+
famílias campeãs
```

O hero continua sendo o principal ponto de descoberta.

Prioridades:

- headline;
- busca;
- Ponto de Origem;
- Feito Em;
- Coordenadas;
- paisagem regional como background;
- produtos e UI renderizados pelo site.

---

# 2. Sua cidade, de 8 jeitos

Função:

```text
explicar o sistema principal da loja
```

Aqui entram as 8 famílias-base:

1. Ponto de Origem
2. Feito Em
3. Coordenadas
4. Legado
5. Território
6. Tipografia
7. Traço
8. Gentílico

Essa seção deve vir imediatamente após o hero.

Ela é o principal eixo comercial depois da busca.

---

# 3. Da Nossa Terra

Mover `Da Nossa Terra` para esta posição.

Ela substitui a antiga posição de destaque que estava sendo ocupada por:

```text
O número de cada região
```

## Papel

Essa seção deve reforçar rapidamente:

```text
regionalismo
+
estado
+
cultura
+
identidade
```

sem depender só de cidade.

É importante que ela apareça cedo porque ajuda o visitante a sentir:

```text
isso é daqui
```

logo depois de entender os 8 estilos.

## Direção visual

Pode ser mais editorial que a seção anterior.

Preferir:

- 4 a 6 produtos;
- boa presença de imagem;
- equilíbrio entre RS, SC e PR quando possível;
- regionalismo real;
- evitar concentração excessiva em bandeiras e clichês.

No mobile:

```text
carrossel horizontal
```

ou composição equivalente com swipe natural.

---

# 4. Escolha seu estado

Manter logo depois de `Da Nossa Terra`.

A lógica fica:

```text
cidade
→ formas de vestir a cidade
→ identidade regional
→ estado
```

Isso cria uma progressão mais natural.

## Mobile

Usar:

```text
accordion / dropdown
```

e não carrossel.

Cada estado recolhido mostra:

```text
nome
quantidade de cidades
```

Ao abrir:

```text
banner/imagem
regiões
produto/linha estadual
CTA
```

Apenas um estado aberto por vez.

---

# 5. Redesenhos / Releituras

Mover para cima de `Feito Para Você` e de `Fala daqui`.

Essa seção deve aparecer logo depois dos estados.

## Papel

Ela representa:

```text
cultura visual
+
referência
+
reinterpretação autoral
```

Não é uma das 8 famílias-base.

Também não deve ser confundida com `Da Nossa Terra`.

## Diferença conceitual

### Da Nossa Terra

```text
regionalismo direto
```

### Redesenhos / Releituras

```text
referências culturais e visuais reinterpretadas
```

## Visual

Pode ter linguagem um pouco mais editorial.

Sugestão:

```text
4 a 6 peças
```

com:

- imagem protagonista;
- nome;
- preço;
- contexto curto, se necessário.

No mobile:

```text
carrossel horizontal
```

---

# 6. Feito Para Você

Manter depois das releituras.

## Papel

Representar:

```text
personalização
+
produto adaptável
+
participação do cliente
```

Essa seção deve ser mais comercial.

## Copy sugerida

Headline:

```text
FEITO PARA VOCÊ
```

Subtexto:

```text
Escolha o modelo, personalize com o seu lugar e deixe a camiseta com a sua cara.
```

Se essa copy prometer algo além do fluxo real, reduzir para:

```text
Escolha entre os modelos personalizáveis e crie uma versão do seu lugar.
```

## Visual

- cards comerciais;
- label `Personalizável`;
- CTA claro;
- sem banner isolado;
- mobile com swipe horizontal.

---

# 7. O número de cada região

Mover DDD para baixo.

Nova posição:

```text
depois de Feito Para Você
antes de Fala daqui
```

## Papel

DDD continua sendo uma camada de identidade.

Mas deixa de ocupar posição alta na home.

Ele passa a funcionar como:

```text
conteúdo de descoberta
+
curiosidade regional
+
produto complementar
```

e não como um dos pilares principais da loja.

## Visual

Manter compacto.

Evitar banner gigante.

Se o banner DDD não melhorar claramente a seção:

```text
não usar o banner
```

---

# 8. Fala daqui

Mover para depois do DDD.

A lógica passa a ser:

```text
número
→ linguagem
```

Isso cria uma sequência editorial coerente.

## Papel

Representar:

```text
expressões
+
linguagem local
+
jeito de falar
```

Manter contexto de origem em cada item.

Não generalizar expressão local como se fosse de todo o Sul.

---

# 9. Campanha editorial

Manter próxima do final.

Ela serve para:

- fechar narrativa;
- reforçar marca;
- trazer fotografia;
- conectar produto + região + manifesto.

Pode usar background integrado.

Nunca como banner solto.

# 12. Densidade

Mesmo com mais seções, a home não pode ficar cansativa.

Cada módulo deve ser compacto.

Especialmente no mobile:

- evitar descrições longas;
- limitar quantidade de cards;
- preferir carrosséis horizontais;
- evitar blocos com altura exagerada;
- não usar banner isolado.

Se a página ficar longa demais, compactar primeiro:

1. DDD;
2. Fala daqui;
3. Redesenhos;
4. Feito Para Você.

Não compactar excessivamente:

- Hero;
- 8 estilos;
- Estados.
